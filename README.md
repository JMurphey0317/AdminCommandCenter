# Admin Command Center for Salesforce

A central dashboard for Salesforce Admins to monitor org health, track user adoption, automation errors, stale records, and performance metrics—all in one place.

## Features
- Visual dashboard of key admin KPIs
- Apex controller for real-time insights
- LWC & Aura-based UI integration
